# 情報源ポリシー

同じ「ネットに書いてある」を同じ強さで扱わない。

# Source Type

## `OFFICIAL-DIRECT`
公式企業・プラットフォームが現在公開するページ。

例：
- KONAMI
- Nintendo
- KADOKAWAの商品書誌
- 国立国会図書館の書誌

用途：発売日、正式名称、書誌、現行ガイドライン。

## `DEV-DIRECT`
開発者本人へのインタビュー。

用途：制作意図、1〜14のつながり、彼女ルートへ接続を隠した理由、裏サクセス開発史。

## `OFFICIAL-GUIDE`
公式攻略本。

書籍の存在確認だけで本文未閲覧のものもある。
本文未確認なのに「攻略本にこう書いてある」と断言しない。
また、攻略Wiki側に公式攻略本の誤記検証ページが残るため、攻略本もゲーム内挙動とクロスチェックする。

## `QA-TRANSCRIPT`
当時のKONAMI公式「しつもんコ～ナ～」やリセット座談会等の回答を、現存する攻略/考察サイトが転記しているもの。

元の公式ページを現在直接確認できない場合、**「公式回答そのものを今確認した」とは扱わない。**

## `ARCHIVE-CITED`
現在は取得できない旧公式ページについて、現存する資料が

- 旧公式ページ名
- 具体的な記述内容
- 可能なら当時URL

まで明示して引用・脚注しているもの。

`QA-TRANSCRIPT` より「どの公式資料を指しているか」は明確だが、原ページ本文を現在直接開けていないため `OFFICIAL-DIRECT` には上げない。

例：
- 旧『パワポケ8』公式サイト「パワポケの歴史」
- URL: `https://www.konami.jp/gs/game/poke/8/history.html`
- 現在は取得不可だが、考察Wikiがこのページを明示的な脚注として引用

公開記事では必要に応じて、
> 現在は消失している『8』旧公式サイト「パワポケの歴史」を出典として保存した資料では〜

のように、原資料が現存しないことを隠さない。

## `EVENT-RECORDED`
攻略Wiki等で具体的な

- イベント名
- 発生時期
- 条件
- プロフィール解禁
- エンド条件

が記録されているもの。

一般的な考察より強いが、ゲームROM・公式テキストそのものではない。

## `MEDIA`
ファミ通等のゲームメディア。

用途：年表クロスチェック、ファンアンケート、編集記事。

## `FAN-RECON`
複数作品の描写を横断してファンが再構成した資料。

用途：調査索引、組織史の仮整理、追加ソース探索。

# Fact Status

## `DIRECT`
公式または開発者が直接確認できる。

## `EVENT-RECORDED`
具体的なゲームイベントの存在・条件が詳細な攻略記録で確認できる。

## `QA-TRANSCRIPT`
当時公式回答の転記のみ現存。

## `ARCHIVE-CITED`
消失した旧公式ページの具体的な出典名・内容・URL等が現存資料で追跡できる。
原文を直接閲覧できないため、断言の仕方は `DIRECT` より一段慎重にする。

## `RECONSTRUCTED`
複数イベントをファン側がつないで成立する解釈。

## `CURRENT-CHECK`
販売・配信・サービス状態など、確認日時点では成立するが将来変化する情報。
必ず確認日を持ち、公開直前に再確認する。

## `OPEN`
まだ記事で確定事項として使わない。

# 「正史」

本記事では、

> 特定彼女ルートの唯一性ではなく、後作でも結果・人物・組織変化が引き継がれている出来事の流れ。

として使う。

旧公式Q&Aの現存転記でも、制作側は正史をなるべく公表せず、一回のプレイでは両立しない出来事が正史では起こる場合がある趣旨を回答している。

# 公開文の強さ

| Fact Status | 推奨 |
|---|---|
| DIRECT | 「〜である」「開発者は〜と説明」 |
| EVENT-RECORDED | 「ゲームには〜というイベントが存在する」「攻略記録では〜」 |
| QA-TRANSCRIPT | 「当時公式Q&Aの現存転記では〜」 |
| ARCHIVE-CITED | 「消失した旧公式ページを明示的に出典とする現存資料では〜」 |
| RECONSTRUCTED | 「〜と整理できる」「ファン資料では〜とされる」 |
| CURRENT-CHECK | 「YYYY-MM-DD時点では〜」 |
| OPEN | 本文へ入れない / 問いとして扱う |

# パワポケ考察Wikiの扱い

本企画では **重要参考先として明記する**。

理由：
- 1〜14をまたぐ人物・組織の索引として非常に有用
- ゲーム内イベント、公式攻略本、旧公式Q&Aの出典を逆引きしやすい
- 消失した旧公式ページの名称・URL・脚注が残る場合がある
- 正史・裏サクセス・人物関係の調査入口として優秀

ただし非公式の有志Wikiであり、記事中では
`EVENT-RECORDED` / `QA-TRANSCRIPT` / `ARCHIVE-CITED` / `FAN-RECON`
を必ず分ける。

読者には「沼へ潜るための最高の入口」の一つとして勧めつつ、公式設定と同一視しない。
