# 紙資料を入手した場合

1. ページ番号を `factcheck.md` に記録
2. 現在 `RECONSTRUCTED` の事実を再評価
3. Wiki由来の説明と食い違う場合、古い説明を残さず修正
4. 必要なら `uncertainties.md` から項目を削除

攻略本の画像・本文全文をリポジトリへ転載しない。
短い要約とページ番号だけを保存する。
