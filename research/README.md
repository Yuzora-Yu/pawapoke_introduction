## sources/
信頼性を担保する領域。

- `policy.md` — 情報源と事実強度
- `index.md` — URL集
- `official-guides.md` — 紙資料の所在
- `factcheck.md` — 現在の事実判定
- `uncertainties.md` — まだ断言しない事項

## 更新ルール

事実を新しく確認したら：

1. テーマ別researchを書き換える
2. `sources/factcheck.md` の該当事実を更新
3. 解消した未確定事項を `sources/uncertainties.md` から削除
4. 新しい出典は `sources/index.md` へ追加

過去の判断を別ファイルとして残さない。
