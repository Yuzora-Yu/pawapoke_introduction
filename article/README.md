# article

公開文章の作業領域。

調査事実は `research/` へ置き、このディレクトリには読者へ見せる文章・構成だけを置く。

現在：
- `outline.md` — 採用構成
- `fragments.md` — 使える文章パーツ

本文を書き始めたら：
- `note.md`
- `full.md`

を追加する。

`draft-v1.md`、`draft-v2.md` のような旧稿ファイルは作らず、改稿履歴はGitで管理する。

追加：
- `preview.html` — 現時点の筆者確認用HTML。右側Tips実装済み
- `ui-notes.md` — 公開サイトでの人物Tips UI案
- `author-note.md` — 13の個人的体験と自作ゲームへの接続
- `related/` — 派生記事計画
