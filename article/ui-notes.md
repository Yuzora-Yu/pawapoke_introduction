# 記事UI — 長文記事で再利用する情報設計

更新：2026-09-06

このUIはパワポケ記事だけの一発ネタにせず、YU-ZORAの今後の長文記事でも流用できる骨格として設計する。

## 1. 本文中Tips

### PC
- 本文右側に sticky Tips レール。
- 本文中の赤い点線 + `?` 付き語をクリックすると内容が切り替わる。
- 説明を本文へ詰め込まず、初見だけ補足できる。

### スマホ
- 本文中Tipsをタップすると dialog。
- 本文の読書位置を失わない。
- Escape / 閉じるボタン / focus復帰を維持。

### Tipsの役割

**固有名詞だけでなく、パワプロ未経験者の「前提語」を救う。**

現在の `data/tips.json` は110語。

追加した基本語の例：
- パワポケ
- 実況パワフルプロ野球
- サクセス
- 表サクセス / 裏サクセス / 第二サクセス
- 彼女候補 / 彼女ルート
- 周回
- アルバム / アルバム登録
- 登録選手
- 真ルート / トゥルーエンド
- 追加イベント
- うろつき
- 正史
- CERO
- サイボーグ / アンドロイド

「パワプロやサクセスを知っている人しか読めない記事」にしない。

## 2. 目次と辞書は右上メニューへ統合

記事末に巨大な辞書を置かない。

右上固定の **CONTENTS / INDEX** ボタンから、右側 drawer を開く。

### CONTENTS
- 全章目次
- クリックで該当章へ移動してdrawerを閉じる

### INDEX
- 110語の全辞書
- テキスト検索
- 人物 / 組織 / 技術 / 能力だけでなく「遊び方」カテゴリも含む
- 項目クリックでdrawer内に説明を表示

これにより、
- 読書中のナビゲーション
- 固有名詞辞書
- 初心者向け基本語辞書

を一か所へまとめる。

## 3. 記事末アクション

本文・SOURCE NOTESのあとに：

- ♥ 好き
- 𝕏 Xで共有
- リンクをコピー

を置く。

### 「好き」について

現行単体HTMLはサーバーを持たないため、クリック状態は `localStorage` のみ。
**公開時に実際の集計をしたい場合はAPI / DBへ接続すること。**

閲覧者向けHTMLにはこの実装メモを表示しない。

## 4. Author

記事の最後の最後だけ。

> **Author　夕空ユウ（@yuu_mintia）**<br>
> 趣味で個人制作のブラウザゲームを公開している。パワポケ、とくに裏サクセスはゲーム制作の大きな原点の一つ。

本文途中にYU-ZORAのゲームページ紹介や「自作ゲームはこちら」を入れない。

## 5. デザイン意図

パワポケ記事の最大の問題は、**説明するとテンポが死に、説明しないと初見が死ぬ**こと。

レイヤーを分ける：

- 本文：布教記事としてテンポ・感情・引きを優先
- Tips：その場で必要な補足
- INDEX：調べたい人向けの全辞書
- CONTENTS：長文移動
- SOURCE NOTES：根拠確認

本文を辞典化しない。
辞典のせいで記事末が重くならない。

## 6. 見た目

- インディーゲーム雑誌の長文特集 + ファン調査資料庫
- 紙色 / 黒 / 赤中心
- 強い罫線、番号、索引
- 本文幅は狭く
- 丸カードの大量配置は避ける
- グラデーション / glassmorphism は使わない
